# BeePlus Delivery App

## Description
BeePlus Delivery App is a visually engaging web application inspired by award-winning delivery websites. Built using HTML, CSS, JavaScript, and GSAP, it demonstrates modern UI/UX design, smooth animations, and interactive elements that enhance the user experience.

## Technologies Used
- HTML
- CSS
- JavaScript
- GSAP (GreenSock Animation Platform)

## Features
- Smooth animations and transitions using GSAP  
- Responsive design for both desktop and mobile devices  
- Interactive navigation and content sections  
- Clean, modern layout inspired by award-winning websites  
- Mobile-first design for enhanced usability
